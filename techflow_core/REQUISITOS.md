
# REQUISITOS — TECHFLOW CORE

## 1. Objetivo

O TechFlow Core tem como objetivo gerenciar demandas, permitindo cadastrar, listar, buscar, atualizar status, excluir e realizar consultas de CEP e cotação.

## 2. Requisitos Funcionais (RF)

**RF01 – Cadastrar demanda:** O sistema deverá permitir cadastrar novas demandas, preenchendo os dados necessários.

**RF02 – Listar demandas:** O sistema deverá apresentar todas as demandas cadastradas.

**RF03 – Buscar demanda:** O sistema deverá permitir localizar uma demanda pelo seu identificador.

**RF04 – Atualizar status:** O sistema deverá permitir alterar o status de uma demanda cadastrada.

**RF05 – Excluir demanda:** O sistema deverá permitir excluir uma demanda após confirmação.

**RF06 – Consultar CEP:** O sistema deverá permitir informar um CEP e consultar os dados do endereço.

**RF07 – Consultar cotação:** O sistema deverá permitir consultar e apresentar uma cotação solicitada.

## 3. Requisitos Não Funcionais (RNF)

**RNF01 – Segurança:** O sistema deverá validar os dados e proteger informações sensíveis.

**RNF02 – Integridade:** O sistema deverá manter os dados corretos e consistentes.

**RNF03 – Usabilidade:** O sistema deverá apresentar menus e mensagens de forma clara e simples.

**RNF04 – Desempenho:** O sistema deverá executar as operações em tempo adequado.

**RNF05 – Disponibilidade:** O sistema deverá tratar falhas nos serviços externos sem encerrar inesperadamente.

## 4. Critérios de aceitação

- Cadastrar uma demanda.
- Listar demandas cadastradas.
- Buscar uma demanda.
- Atualizar o status.
- Excluir uma demanda.
- Consultar CEP.
- Consultar cotação.
- Apresentar mensagens claras de erro.
